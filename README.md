## Ответы на вопросы

**1. Чем Console.Write() отличается от Console.WriteLine()?**

Console.Write() выводит текст в консоль и оставляет курсор на той же строке. Следующий вывод продолжится сразу после предыдущего.
Console.WriteLine() выводит текст и переводит курсор на новую строку. Каждый следующий вывод начнётся с новой строки

**2. Что произойдёт, если попытаться присвоить переменной типа int значение 3.14?**

Компилятор выдаст ошибку на этапе сборки, потому что 3.14 — это число с плавающей точкой (тип double), а int может хранить только целые числа. 
Чтобы код заработал, нужно либо использовать тип double, либо явно привести значение: int x = (int)3.14; (тогда дробная часть отбросится и получится 3)

**3. Почему 10 / 3 в C# даёт 3, а не 3.333...? Как получить дробный результат?**

Потому что оба числа (10 и 3) являются целыми (int). В C# при делении целых чисел выполняется целочисленное деление, при котором дробная часть отбрасывается.
Чтобы получить дробный результат, хотя бы одно из чисел должно быть типа double:
```csharp
double result = 10.0 / 3;      // 3.333...
double result2 = (double)10 / 3; // 3.333...
```

**4.Что означает var в C#? Чем он отличается от динамической типизации в Python?**

var — это ключевое слово, которое позволяет компилятору самостоятельно определить тип переменной по значению, присвоенному ей при объявлении

Ключевое отличие от Python: в C# тип определяется один раз и навсегда на этапе компиляции. После этого переменная не может хранить значение другого типа. В Python переменная может менять тип в любой момент (динамическая типизация). То есть var — это не «динамический тип», а просто удобная сокращённая запись для компилятора
